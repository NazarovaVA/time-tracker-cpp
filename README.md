# <img src="https://media.tenor.com/brmfHHFqlhEAAAAi/hourglass-time.gif" alt="" style="height: 1.2em; vertical-align: -0.15em;"> Time Tracker (Тайм-трекер)

**Статус проекта:** В разработке.

Десктопное приложение для персонального учёта рабочего времени. Позволяет создавать задачи, замерять время с помощью встроенного таймера, анализировать статистику и экспортировать данные.

Проект выполнен в рамках дисциплины «Технологии индустриального программирования».

## Планируемые возможности

- **Управление задачами**: создание, редактирование и удаление задач с указанием категории и тегов. Цветовая индикация по категориям.
- **Учёт времени**: удобный таймер с поддержкой старта, паузы, продолжения и отмены. Автоматическая разбивка записей, переходящих через полночь.
- **Работа с записями**: таблица с сортировкой, фильтрацией по датам, категориям и тегам, а также поиском.
- **Ручной ввод**: добавление записей вручную, если вы забыли запустить таймер.
- **Аналитика**: сводная статистика, сравнение с прошлым периодом, графики (круговая и столбчатая диаграммы).
- **Удобство**: работа в системном трее, горячие клавиши, поддержка светлой и тёмной темы.
- **Надёжность**: автосохранение в JSON, резервные копии (`.bak`), восстановление незавершённого таймера после сбоя.
- **Данные**: экспорт и импорт в CSV.

## Технологический стек

- **Язык**: C++17
- **Фреймворк**: Qt 6.8 LTS (Core, Gui, Widgets)
- **Система сборки**: CMake (≥ 3.16)
- **Хранение данных**: JSON
- **Графики**: QPainter (без внешних библиотек)

## Как запустить (инструкция для будущей сборки)

Когда исходный код будет добавлен в репозиторий, сборка будет осуществляться следующим образом:

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/your-username/time-tracker.git
   cd time-tracker
   ```

2. Создайте папку для сборки:

   ```bash
   mkdir build && cd build
   ```

3. Сгенерируйте конфигурацию и соберите проект:

   ```bash
   cmake ..
   cmake --build . --config Release
   ```

4. Запустите приложение (Windows / Linux):
   ```bash
   ./TimeTracker
   ```
